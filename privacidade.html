Política de privacidade

Atualizada em 7 de novembro de 2026

Esta política explica como o aplicativo Café com Horóscopo usa os dados acessados por meio das APIs do Google.

O que o aplicativo faz

O Café com Horóscopo é uma ferramenta de uso próprio que envia automaticamente vídeos de horóscopo para o canal do YouTube Café com Horóscopo, pertencente ao responsável por este aplicativo.

Quais dados são acessados

O aplicativo solicita apenas a permissão de envio de vídeos ao YouTube (escopo youtube.upload). Ele não lê, coleta nem armazena dados pessoais de espectadores ou de outras contas, e não acessa e-mails, contatos, arquivos ou qualquer outra informação da conta Google.

Como os dados são usados e guardados

  • A autorização é usada exclusivamente para publicar vídeos no canal do próprio responsável pelo aplicativo.
  • As credenciais de acesso ficam guardadas como segredos criptografados no ambiente de automação e não são exibidas publicamente.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
